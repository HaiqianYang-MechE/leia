# Datasets

LEIA's two paper datasets are both regimes of the **MicroPlate** benchmark.

## MicroPlate lattice

Architected lattice plates under quasi-static Neo-Hookean deformation.

| Property | Value |
|---|---|
| Plates | 55 training + 8 held-out |
| Mesh size | 71K – 442K nodes per plate |
| Material | Neo-Hookean, μ=1, λ=10 |
| Action | 4-DOF cumulative BC: stretch, twist, shear_y, shear_z |
| Trajectories | ≥ 101 per training plate (the first 100 train, the rest validate); held-out plates: whatever converges |
| Frames per trajectory | 31 |

Generated by `data_curation/fem/run_plate_fem.py` (FEniCS / dolfin), one trajectory per process, MUMPS solver; left face clamped, right face displacement-driven (Dirichlet).

## MicroPlate visco

Single homogeneous plate under viscoelastic load-reversal protocol.

| Property | Value |
|---|---|
| Mesh size | 363 nodes (fixed) |
| Material | Arruda-Boyce + 3-branch viscoelastic (Geq=200, G=[300,600,150], τ=[0.001,0.2,3.0]) |
| Action | 4-DOF per-step increments (±1/0 per DOF; the dynamics model is driven by the raw increments, not cumulative BC); 100 action steps (50 forward + 50 exact reverse) |
| Trajectories | 1000 (split 800 / 100 / 100) |

Why visco is harder: matched cumulative-BC points between forward and reverse halves have different (u, σ) due to viscoelastic memory; models that ignore history fail this.

Generated by `data_curation/fem/run_visco_load_reverse.py` (FEniCSx / dolfinx 0.8) and packaged into `data/microplate_visco/microplate_visco.h5`.

## Building the data

No bulk artifacts are hosted. FEM trajectories, canonical tet meshes, and the
visco HDF5 are generated locally with the pipelines in
[`../data_curation/`](../data_curation/README.md); checkpoints are trained from
them (see `README.md`).

Derived caches (`fps/`, `grad_u/`, `plate_tet_geom/`, the tokenizer and dynamics
mmaps) are regenerated locally: commands in `README.md § 2. Precompute caches`,
layout and timings in [`../data/README.md`](../data/README.md).

## Meshes

Plate graphs at `data/rve_bank/{plate}/graph.json` are the canonical topology spec. `python data_curation/mesh/build_meshes.py --all` builds the tet meshes from them via `physics.meshing.mesh_graph(graph, tiles=(5,5,1), res_per_cell=30)` (the TetGen switch ladder is fixed in `physics/meshing/_tetgen.py`).

| `microplate_visco_splits.json` | train/val/test split (800/100/100) |
